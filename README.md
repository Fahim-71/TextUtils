# TextUtils

TextUtils is a simple React app for editing and reviewing text in the browser.

## Features

- Convert text to uppercase or lowercase.
- View word and character counts.
- See an estimated reading time.
- Preview the current text.

## Getting Started

### Prerequisites

- Node.js and npm

### Installation

1. Clone the repository and move into the project directory.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm start` | Start the development server. |
| `npm run dev` | Start the development server. |
| `npm test` | Run the test suite. |
| `npm run build` | Create an optimized production build in `build/`. |
| `npm run eject` | Eject the Create React App configuration. This cannot be undone. |
